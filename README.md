# Online Retail Analysis Dashboard

## Objective
To analyze online retail sales data and create an interactive
dashboard for identifying sales trends and key performance metrics.

## Tools
- Power BI
- SQL
- Excel

## Key Analysis
- Sales trends
- Revenue and profit analysis
- Product and sub-category performance
- Customer segment analysis
- Shipping mode analysis
